# 📊 React Dashboard UI

A modern and responsive dashboard built using **React, Tailwind CSS, and Recharts**.  
This project displays business analytics including revenue, profit, customers, orders, and category-wise sales distribution with rich visual charts.

---
## Live Demo

https://statsparevicky.vercel.app/

## 🚀 Features

- Clean & responsive dashboard layout  
- Statistic cards with growth indicators  
- Sales overview chart with metric filter  
- Monthly comparison (Bar Chart)  
- Category-wise sales visualization (Pie Chart)  
- Recent orders table with status badges  
- Reusable and maintainable component structure  
- Mock data structure prepared for API integration
---

## 🛠 Tech Stack

- **React.js**
- **Tailwind CSS**
- **Recharts**
- **Lucide Icons**
